# OpenLP: Multi-Block Lyrics Fork 🎤

Welcome to a custom fork of OpenLP! This version is optimized for modern worship environments, featuring a **Three-Block Vertical Lyrics** display mode.

## ✨ Key Feature: Multi-Block Lyrics
Standard OpenLP shows one slide at a time. This fork introduces a "Vertical Stack" mode that displays:
1. **The Previous Slide** (Above)
2. **The Current Slide** (Centered/Highlighted)
3. **The Next Slide** (Below)

This helps both the congregation and the worship team see what's coming next without losing the context of the current verse.



## 🚀 How to Use
1. **Launch OpenLP** using your virtual environment.
2. Look at the **Live Slide Controller** (the panel where you change slides).
3. Find the new **"Show Three Blocks"** button in the toolbar (indicated by the loop/stack icon).
4. **Toggle ON:** The display immediately switches to the vertical three-block view.
5. **Toggle OFF:** The display reverts to the classic single-slide view.
